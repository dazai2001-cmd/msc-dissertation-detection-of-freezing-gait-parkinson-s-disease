# Freezing of Gait Detection in Parkinson’s Disease using Machine Learning

## Overview
This project focuses on detecting **Freezing of Gait (FoG)** episodes in patients with **Parkinson’s Disease** using machine learning techniques. Freezing of Gait is a common symptom where patients temporarily lose the ability to move forward while walking.

The aim of this work is to develop a data-driven approach to identify FoG patterns and support early detection and intervention.

---

## Objectives
- Analyse movement data related to Parkinson’s disease
- Identify patterns associated with Freezing of Gait episodes
- Build machine learning models for detection/classification
- Evaluate model performance using standard metrics

---

## Methodology
The project follows these steps:

1. Data collection and preprocessing  
2. Feature engineering and selection  
3. Model training (Machine Learning / Deep Learning approaches)  
4. Evaluation and performance comparison  
5. Result analysis and interpretation
